# Pockt Full Layout & UI Overhaul Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Overhaul Pockt's layout, information hierarchy, and component chrome across all views based on the Wise-inspired Scandinavian fintech design system in `.agents/DESIGN.md`, enforcing strict 3-tier font hierarchy, boxed icon containers, refined elevation and padding, while maintaining 100% responsiveness and zero regression in E2E tests.

**Architecture:**
1. **Layout Shell & Chrome (`+layout.svelte`)**: Upgrade desktop sidebar and mobile header/drawer with boxed squircle icon containers, enhanced active states, and refined structural padding.
2. **Dashboard (`/dashboard/+page.svelte`)**: Re-architect the Hero Free-to-Spend section, equation breakdown card, 4-stat cards grid, and timeline ledger rows with strict 3-tier typography and boxed icons.
3. **Payday Allocation Matrix (`/payday/+page.svelte`)**: Restructure monthly salary vs commitment cards, add visual cash-flow commitment distribution meter, and elevate header/settings controls.
4. **Transactions Ledger (`/expenses/+page.svelte` & `/incomes/+page.svelte`)**: Standardize filter chip bar, search row, summary hero card, and list items with boxed icons and responsive alignment.
5. **Bills & Debts Register (`/bills/+page.svelte`, `/debts/+page.svelte`, `/settled/+page.svelte`)**: Polish bill cards with due date calendar pills, debt progress indicators, and compact action button groups.
6. **Form & Modal System (`Modal.svelte`, `QuickAddModal.svelte`, `AmountInput.svelte`, `SortDropdown.svelte`)**: Enhance modal chrome, segmented controls, input spacing, and button touch targets (44px min).

**Tech Stack:** SvelteKit 5, Tailwind CSS v4, TypeScript, Lucide Icons, Playwright E2E.
